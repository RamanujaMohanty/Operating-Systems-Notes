# Unit 2 Notes | Operating Systems Structure
## 2-2 - User Interface
- **Command Line Interpreter (CLI)**
  - Allows direct command entry
  - Sometimes implemented in kernel, sometimes by system program.
  - Sometimes multiple flavors implemented - **shells**
  - Sometimes commands are built-in, sometimes they're just names of programs.
    - If it's the latter, adding new features doesn't require shell modification.
- **User Operating System Interface - GUI**
  - User-friendly desktop metaphor interface
  - Icons represent files, programs
  - Windows, Aqua, CDE, KDE, GNOME
- **Touchscreen Interface**
  - Action and selection based on gestures
  - Virtual keyboard for text entry
  - Voice commands
